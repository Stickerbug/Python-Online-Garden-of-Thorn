把引擎里所有"卡专用原子"（`game_engine.py` 里形如 `_atomic_<包名或卡名>_*` 的实现）彻底改写成
GTN Mod Spec v2 的**通用数据步骤**，引擎里只保留可复用的通用原子。

- 不必保留兼容（目前没有社区模组）；
- 允许修改所有卡数据（`mods/*.gtnmod`）与其他数据；
- 卡牌描述必须符合 `docs/卡牌描述规范.md`；
- 未获授权**不要部署**、不要重启线上服务。

## 四、流程（每批都照这个做）

1. 读该原子的实现与它的调用卡数据；
2. 在 `tools/refactor_card_atoms.py` 增加改写规则（优先用已有通用原子；确实缺能力才加**通用**新原子）；
3. 跑 `tools/refactor_card_atoms.py`；
4. 跑 `tools/remove_engine_atoms.py --apply <旧 op>`；
5. 跑受影响测试文件 + `smoke_all_cards.py`；
6. 若是老测试直接调用被删的原子，改测试让它走 `play_card` 真实数据路径（参考 `tests/test_bio_diamond_description.py`）。
